ADDITIONAL FEATURES

TrueForge integration and optional controls
  Official SDK sessions and TrueForge's agent loop; versioned agent manifest,
  MCP discovery and approval events. The final editor B retake used genuine
  deferred discovery with preloadTools=false. Optional preloading supports
  models with schema limitations and retains approvals. Optional reasoning
  effort is passed through the TrueForge agent spec. Supported operator
  questions resume with the real answer; dismissal cancels, and cancellation
  prevents late answers. Empty output and no-edit runs report their outcome.

Automatic configured-model fallback
  Real Task C showed an unreachable primary connection, then automatically
  started Gemini 3.1 Flash Lite and reached done with two scoped hunks.
  During review the user rejected one hunk and accepted the other into an
  unsaved buffer. Stop discarded pending work, then guarded Undo/Save All
  restored the accepted buffer.
  Post-recovery Git status was clean and all 235 tracked hashes matched the
  pre-C state. Fallback requires a stopped prior turn and no staged edits.

Optional local compatibility and diagnostic helpers
  The Groq gateway has offline fake-upstream coverage for routing, auth,
  size limits, incremental streaming, retry and redirect behavior. Live
  provider compatibility remains unverified; its current request deadline
  does not interrupt a slow incoming body upload. The optional Python AST
  gate parses without execution and rechecks the actual materialized
  candidate before staged-state/evidence mutation. Its batched-approval
  regression preserves the prior overlay, evidence and target on failure.
  Updated source: 113/113 offline tests and TypeScript checking passed.
  These helpers do not change the recorded extension bundle.

Bounded execution and commands
  Configurable total-run deadline (five-minute default), separate model-call
  timeout (two-minute default), and TrueForge's 40-iteration limit. Native
  bounded HTTP backoff handles explicit transient provider responses; no
  blind replay after ambiguous interruption. Concurrent runs are rejected.
  Validation commands require separate approval and a narrow allowlist.
  Tests/imports execute trusted workspace code; no arbitrary shell tool.

Workspace and transport protections
  Ephemeral authenticated loopback MCP; traversal, protected-path, symlink,
  binary and oversized-file exclusions. Requests are limited to 2 MiB and
  512 raw tool-input elements before schema expansion. Normal requests,
  oversized/chunked bodies and excessive/nested inputs have regression
  coverage. Late or cancelled operations fail before changing editor state.

Provider configuration and provenance
  Credentials remain in TrueForge. Primary and fallback model IDs are
  independently configurable. Built from scratch with AI coding assistance;
  MIT license and runtime dependency licenses are included in LICENSE and
  THIRD_PARTY_NOTICES.md. The iterative B review corrections are disclosed;
  the focused model follow-up is separate from the original exact prompt.
  This checkpoint does not claim an unassisted one-shot model result.
