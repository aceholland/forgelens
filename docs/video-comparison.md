# ForgeLens and the Countersign demo

Both projects run TrueForge against the same Flask revision. Countersign’s video shows its agent completing Task B in one turn with a native scout and 25 tool calls. ForgeLens has a separately reproducible four-file model patch. Its historical generation used one procedural clarification, and its recorded Round 1 run used a follow-up. The projects added different tests, so the CLI test counts measure different suites. [Countersign’s timestamped demo notes](https://github.com/kinnuworks/countersign#countersign) · [ForgeLens historical run and patch](evidence/task-b-flash-lite/README.md)

A second Windows fixture delivered an actual assertion failure to the running model, reviewed the repair, and passed pytest in the same turn. [Recording and results](live-review-check.md)
